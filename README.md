# HumanSkill-4D: Training-Free Language Querying of Animatable Gaussian Avatars in Space and Time

Junsu Kim<sup>1</sup>, Naeun Kim<sup>1</sup>, Dongyoon Han<sup>2,†</sup>, Seungryul Baek<sup>1,†</sup>

<sup>1</sup>UNIST &nbsp; <sup>2</sup>NAVER AI Lab &nbsp; <sup>†</sup>Corresponding authors

HumanSkill-4D selects the parts and garments of an animatable Gaussian avatar that a language query asks
for and, when the query names a motion, the moments it happens. No training is needed.
